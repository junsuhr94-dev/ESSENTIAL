# Perfect Score

라이브 공연·세션 연주자를 위한 iPad 악보 뷰어 & 스마트 필기 앱 (PWA).

> **현재 진행: 3단계 완료**
> 1단계 — 프로젝트 셋업, PDF/이미지 렌더링, 블루투스 페달, 페이지 전환(즉시 / 반 페이지 / 가로·세로 스크롤)
> 2단계 — Konva 필기 레이어, 손글씨 음악 기호 자동 정돈(SMuFL), 코드 네임 텍스트
> 3단계 — 세트리스트, 공연 모드, 야간/아날로그 테마·디밍, 여백 자동 자르기, 메트로놈, 북마크·마디 번호 이동

## 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | React 19 + Vite + TypeScript | 서버 없이 정적 파일로 빌드되어 완전 오프라인 PWA와 Capacitor(iOS 앱) 포장에 가장 단순함 |
| 스타일 | Tailwind CSS v4, Lucide 아이콘 | |
| UI | shadcn/ui 방식 컴포넌트 (Radix UI 기반, `src/components/ui`) | `components.json` 포함 — `npx shadcn add …` 로 추가 가능 |
| PDF | `pdfjs-dist` (legacy 빌드, 웹 워커, `enableHWA`) | iPadOS 구버전 호환 + GPU 가속 캔버스 |
| 음악 폰트 | Bravura (SMuFL 표준, `@fontsource/bravura`) | 번들에 포함되어 오프라인에서도 사용 |
| 필기 | Konva.js (React 래퍼 없이 직접 제어) | 저장된 필기와 그리는 중인 획을 다른 레이어로 나눠 그리는 중에는 획 하나만 다시 그림 |
| 기호 인식 | $P 점 구름 인식기 + 규칙 + 오선 검출 (직접 구현) | 외부 서버·학습 모델 없이 기기에서 즉시 동작 |
| 상태 | zustand (설정은 localStorage에 저장) | |
| 저장소 | IndexedDB (`idb`) | 악보 원본·메타데이터를 기기 안에 저장 |
| PWA | `vite-plugin-pwa` (Workbox) | 앱 셸·pdf.js 워커·폰트 프리캐시 |
| 테스트 | Vitest | 넘김 모델·페달 로직 단위 테스트 |

Next.js 대신 Vite를 쓴 이유: 이 앱은 서버 기능이 없는 오프라인 앱이라 Next.js의 SSR·라우팅 장점이 거의 없고, Capacitor는 정적 `dist/` 폴더를 그대로 포장합니다. 나중에 Next.js로 옮기더라도 `src/core`는 프레임워크와 무관한 순수 TypeScript라 그대로 쓸 수 있습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 iPad에서 http://<PC IP>:5173 접속 가능)
npm test           # 단위 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 확인 (서비스 워커 동작)
npm run icons      # 앱 아이콘 다시 생성 (Playwright 필요)
```

### iPad에 설치

1. `dist/`를 HTTPS로 호스팅합니다(GitHub Pages, Netlify, Vercel 등 — 상대 경로로 빌드되어 하위 경로도 가능).
2. iPad Safari로 접속 → 공유 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없는 전체 화면으로 열리고, 오프라인에서도 동작합니다.

> Safari 탭에서만 쓰면 iPadOS가 오래 쓰지 않은 사이트의 데이터를 지울 수 있습니다. 반드시 홈 화면에 추가해서 쓰세요.

App Store 배포나 파일 앱 연동이 필요해지면 Capacitor로 포장합니다: `npm i @capacitor/core @capacitor/ios && npx cap init "Perfect Score" com.example.perfectscore --web-dir dist && npx cap add ios` (Xcode가 있는 Mac 필요).

## 1단계 기능

- **악보함**: PDF 여러 개 가져오기, 악보 사진 여러 장 → 한 곡으로 묶기, 썸네일, 검색·정렬, 이어보기
- **페이지 넘김 방식**
  - **즉시 전환**: 다음/이전 화면을 미리 렌더링해 두고 캔버스 노드만 교체 → 페달과 같은 프레임에 전환
  - **반 페이지 넘김**: `[3쪽] → [위: 4쪽 윗부분 / 아래: 3쪽 아랫부분] → [4쪽]`. 두 쪽 보기에서는 `[1|2] → [3|2] → [3|4]`처럼 이미 연주한 쪽부터 교체. 경계 위치(30~70%) 조절 가능
  - **가로 / 세로 부드러운 스크롤**: 보이는 페이지만 렌더링. 세로는 한 번에 화면의 85%씩 이동해 시선이 이어짐
- **블루투스 페달**: ←/→, ↑/↓, PageUp/PageDown, Space, Enter 기본 지원
  - 길게 눌렀을 때의 자동 반복과 접점 튐(150ms)을 무시 → 두 장이 넘어가는 사고 방지
  - 설정 창에서 들어오는 키를 실시간 확인하고, "페달로 지정"으로 원하는 키를 학습
- **자동 레이아웃**: 가로 = 두 쪽, 세로 = 한 쪽. 회전해도 보던 페이지 유지
- 화면 좌우 탭(끌 수 있음) · 스와이프 · 가운데 탭으로 메뉴 숨김, 연주 중 화면 꺼짐 방지

## 구조

```
src/

    document/              #   ScoreSource 추상화: PDF(pdf.js) / 이미지 묶음
    render/renderCache.ts  #   렌더링 캔버스 LRU 캐시 (iOS 캔버스 메모리 관리)
    navigation/navigator.ts#   페이지 넘김 상태 모델 (즉시·반 페이지, 한 쪽·두 쪽)
    pedal/                 #   키 매핑, PageTurner (반복·튐 방지, 입력창 무시)
    ink/                   #   필기 데이터 모델·기하 계산
    recognition/           #   $P 인식기, 기호 템플릿, 오선 검출, 글리프 배치
    input/                 #   펜슬 사용 중 손바닥 무시
    metronome/             #   Web Audio 메트로놈, 탭 템포
    setlist/               #   세트리스트 순서·마디 번호 → 페이지
    render/autoCrop.ts     #   여백 자동 자르기(내용 영역 찾기)
  features/
    library/               # 악보함, 가져오기
    viewer/                # PagedView(즉시·반 페이지), ScrollView, 설정 창
    ink/                   # Konva 필기 레이어, 도구 막대, 기호 변환 연결
    setlist/               # 세트리스트 목록·편집
    metronome/             # 메트로놈 패널, 박 표시·깜빡임
  components/ui/           # shadcn/ui 컴포넌트 (Radix)
  hooks/                   # usePageTurner, useWakeLock, useElementSize
  lib/                     # db(IndexedDB), smufl(음악 글리프 맵), utils
  stores/                  # zustand: 보기 설정, 필기 데이터·실행 취소, 토스트
  pwa/                     # 서비스 워커 등록·업데이트 알림(공연 중 자동 새로고침 방지)
```

## 2단계 기능 — 필기 & 스마트 기호 정돈

- **필기 도구**: 펜(필압 반영) · 형광펜 · 지우개(획·기호·텍스트) · 코드 네임/텍스트 · 선택(이동·크기 조절·삭제), 색·굵기, 실행 취소/다시 실행(⌘Z)
- **Apple Pencil 바로 쓰기**: 필기 모드를 켜지 않아도 펜슬로 바로 써지고, 손가락은 페이지 넘김에만 쓰인다. 펜슬을 쓰는 중·직후 0.7초의 손바닥 터치는 무시한다.
- **손글씨 기호 자동 정돈** (“기호 정돈” 켜기):
  1. 이어서 그린 획들(0.65초 이내, 가까운 위치)을 한 기호로 묶는다.
  2. $P 점 구름 인식기로 템플릿과 비교한다. 획 순서·방향·획 수와 무관하다.
  3. 렌더링된 악보에서 **오선을 자동으로 찾아** 칸 크기를 구한다.
  4. Bravura 글리프를 그 크기(오선 높이 = 1em)로 놓고, 음표 머리·임시표는 가장 가까운 **줄/칸에 스냅**한다.
  5. 확신이 낮으면 손글씨를 그대로 둔다. 잘못 바뀌었으면 실행 취소 한 번으로 손글씨로 돌아간다.
- **인식하는 기호**: 4분·2분·8분음표(줄기 위/아래), 음표 머리, 온음표, 4분·8분쉼표, ♯ ♭ ♮, 악센트, 스타카토, 테누토, 페르마타, X 머리, 리듬 슬래시, 도돌이표(시작/끝), 코다, 페달(Ped.) / 페달 떼기(*)
- **코드 네임**: 텍스트 도구로 `F#m7b5`를 입력하면 #, b 가 SMuFL 임시표(♯ ♭)로 표시된다.
- 필기는 페이지 폭 기준 좌표로 IndexedDB 에 저장된다. 회전·레이아웃·반 페이지 넘김·스크롤 모드 어디서나 제자리에 보인다.

새 기호를 추가하려면 `src/core/recognition/templates.ts`의 `SYMBOL_CLASSES`에 도형을 추가하면 된다. `npm test`의 합성 손글씨 정확도 테스트로 바로 확인할 수 있다.

## 3단계 기능 — 공연

- **세트리스트** (악보함 → 세트리스트 탭)
  - 공연 순서대로 곡을 묶고 순서를 바꾼다. 같은 곡을 두 번 넣을 수도 있다.
  - **공연 시작**을 누르면 곡마다 첫 페이지부터 열린다.
  - 마지막 페이지에서 페달을 한 번 더 밟으면 “다음 곡: …” 안내가 뜨고, 3초 안에 한 번 더 밟으면 다음 곡으로 넘어간다(실수로 넘어가는 것 방지).
  - 상단 ⏮/⏭ 버튼, 또는 페달 설정의 **다음 곡/이전 곡** 키로 바로 넘어갈 수 있다(기본 키 `]` `[` — 4페달 페이지 터너의 3·4번 페달에 지정 권장).
- **공연 모드** (🔒): 필기 입력과 메뉴를 잠근다.
  - 화면 가장자리 18% 탭, 스와이프, 페달로만 넘어간다.
  - 가운데를 짚어도 아무 일도 일어나지 않고, 길게(0.65초) 누르면 메뉴가 열린다.
- **화면** (🎨)
  - 악보 색: 기본 / 아날로그(세피아) / 야간(검은 바탕·흰 음표 — 필기도 함께 반전)
  - 화면 어둡게: 0~80%
- **여백 자동 자르기**: 곡마다 켜고 끈다. 저해상도로 페이지를 훑어 잉크가 있는 영역만 크게 보여준다. 계산 결과는 저장되고, 필기 좌표는 자르기와 무관하게 유지된다(즉시 전환·반 페이지 넘김에서 적용).
- **메트로놈** (⏱)
  - Web Audio 예약 방식이라 박이 흔들리지 않는다.
  - 탭 템포(간격의 중앙값 사용), 박자 1~7, 첫 박 강세를 지원한다.
  - **소리 끄기**를 누르면 화면 가장자리 깜빡임으로만 박을 보여준다(인이어 없이 눈으로 템포 확인).
  - 템포는 곡마다 저장되어 세트리스트에서 곡이 바뀌면 그 곡의 템포로 바뀐다.
- **빠른 이동·북마크** (↪)
  - 페이지 번호로 이동하거나, 북마크를 추가한다(예: “코러스”, “D.S.”).
  - 북마크에 시작 마디를 적어 두면 **마디 번호로 이동**할 수 있다(17마디 = 2쪽이면 25마디 → 2쪽).
  - 숫자 키 1~9 로 북마크에 바로 간다.

> iPad 무음 스위치(또는 제어 센터의 무음 모드)가 켜져 있으면 웹 오디오 메트로놈 소리가 나지 않을 수 있다. 이때는 깜빡임 모드를 쓰면 된다.

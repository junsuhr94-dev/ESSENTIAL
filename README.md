## 📁 perfect-score/

**Perfect Score** — 라이브 공연·세션 연주자를 위한 iPad 악보 뷰어 & 스마트 필기 앱 (1~3단계 완료: 페달·반 페이지 넘김, 스마트 필기, 세트리스트·공연 모드·메트로놈).
프로젝트 전체가 [`perfect-score/`](perfect-score/) 폴더 안에 있습니다. 자세한 내용은 [perfect-score/README.md](perfect-score/README.md)를 보세요.

### 바탕화면에 “perfect score” 폴더로 받기

**방법 1 — ZIP 다운로드 (Git 없이)**
1. GitHub 저장소 페이지에서 브랜치를 `claude/sheet-music-viewer-yf4uo4`로 바꿉니다.
2. **Code → Download ZIP**을 누릅니다.
3. 압축을 풀고 안의 `perfect-score` 폴더를 바탕화면으로 옮깁니다.

**방법 2 — Git (터미널)**
```bash
# macOS
git clone -b claude/sheet-music-viewer-yf4uo4 https://github.com/junsuhr94-dev/ESSENTIAL.git ~/Desktop/ESSENTIAL
cd ~/Desktop/ESSENTIAL/perfect-score && npm install && npm run dev
```
Windows(PowerShell)에서는 `~/Desktop` 대신 `$HOME\Desktop`을 쓰면 됩니다.

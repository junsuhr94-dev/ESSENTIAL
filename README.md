# 악보 뷰어 (iPad용 PDF 악보 앱)

아이패드 사파리에서 **홈 화면에 추가**해 앱처럼 쓰는 PDF 악보 뷰어입니다. 설치 후에는 오프라인에서도 동작하며, 악보와 필기는 기기 안(IndexedDB)에만 저장됩니다.

## 기능

- **악보함**: PDF 여러 개 한 번에 가져오기(파일 앱·iCloud Drive), 썸네일, 검색, 정렬, 이름 바꾸기, 삭제, 마지막으로 본 페이지 기억
- **페이지 넘김**
  - 화면 오른쪽/왼쪽 30% 탭 → 다음/이전, 가운데 탭 → 메뉴 표시/숨김
  - 좌우 스와이프
  - **블루투스 페이지 넘김 페달**(AirTurn, PageFlip 등): 방향키 · PageUp/PageDown · 스페이스 지원
  - 하단 슬라이더로 원하는 페이지로 이동
- **보기 방식**: 자동(가로는 두 쪽, 세로는 한 쪽) / 한 쪽 / 두 쪽
- **Apple Pencil 필기**: 펜(필압 반영) · 형광펜 · 지우개(획 단위), 색과 굵기 선택, 실행 취소/다시 실행
  - 펜슬은 필기 모드가 아니어도 바로 써지고, 손가락은 페이지 넘김에만 쓰입니다(손바닥 오인 방지). 필요하면 “손가락 필기”를 켤 수 있습니다.
  - 필기는 페이지 크기 비율로 저장되어 가로/세로를 바꿔도 위치가 맞습니다.
- 연주 중 **화면 꺼짐 방지**(Screen Wake Lock 지원 기기)
- 다음/이전 페이지를 미리 그려 두어 페이지 넘김이 즉시 이루어집니다.

## 아이패드에 설치하기

이 앱은 정적 파일만으로 동작하므로 HTTPS로 호스팅만 하면 됩니다. 예: GitHub Pages

1. GitHub 저장소 **Settings → Pages**에서 이 브랜치(또는 main)의 루트 폴더를 배포합니다.
2. 아이패드 사파리에서 배포된 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가**.

> 홈 화면에 추가하지 않고 사파리 탭에서만 쓰면, iPadOS가 오래 쓰지 않은 사이트의 데이터를 지울 수 있습니다. 반드시 설치해서 사용하세요.

## 로컬에서 실행

```bash
npx http-server . -p 8080
# 또는
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다(`file://`로 열면 모듈과 서비스 워커가 동작하지 않습니다).

## 구조

```
index.html              화면 골격
css/app.css             스타일
js/app.js               진입점, 화면 전환, 서비스 워커 등록
js/library.js           악보함(가져오기, 목록, 메뉴)
js/viewer.js            악보 보기(레이아웃, 렌더링 캐시, 입력, 필기, 실행 취소)
js/ink.js               스트로크 그리기와 지우개 판정
js/pdf.js               pdf.js 래퍼
js/db.js                IndexedDB 저장소
sw.js                   오프라인 캐시
vendor/pdfjs/           Mozilla pdf.js 4.10.38 (legacy 빌드, Apache-2.0)
```

앱 파일을 수정한 뒤 배포할 때는 `sw.js`의 `VERSION`을 올려 주세요.

## 앞으로 추가할 만한 것

- 세트리스트(여러 악보를 순서대로 묶어 연속 넘김)
- 반 페이지 넘김, 확대/축소
- 필기를 포함한 PDF 내보내기, 백업/복원
- 텍스트·음악 기호 스탬프
